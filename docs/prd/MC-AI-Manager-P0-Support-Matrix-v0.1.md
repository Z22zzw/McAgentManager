## 1. 承诺定义

| 标记 | 含义 |
|---|---|
| ✅ 自动闭环 | 纳入 P0 Golden Sample、BDD 和回归；合法输入应自动创建并验证实例 |
| 🟨 识别并停止 | 能解释输入类型和不支持原因，但不自动运行 |
| 🧪 兼容观察 | 可能可以运行，但不计入 P0 承诺、指标和缺陷 SLA |
| ❌ 不支持 | P0 不处理或明确拒绝 |

“自动闭环”只适用于同时满足操作系统、MCSManager、Java、ZIP 结构、核心和 MC 版本要求的组合。

### 3.1 必须通过的 API 契约

- 认证和会话。
- 实例列表、详情、状态。
- 实例创建。
- 启动、正常停止和目标状态验证。
- 控制台日志或日志流。
- 实例配置读取与受限修改。
- 实例删除或解除注册。
- 对应实例高级入口。
- API 错误、超时、重复请求和服务离线行为。

## 5. 服务端输入结构

| 输入 | 状态 | 识别与处理 |
|---|---:|---|
| 单层目录内的完整 Vanilla JAR 服务端 | ✅ | 识别 JAR、配置和世界，生成启动命令 |
| ZIP 根目录即服务端目录 | ✅ | 直接进入识别 |
| ZIP 外包一层同名目录 | ✅ | 自动剥离唯一公共根目录 |
| Paper 完整服务端 | ✅ | 识别 Paper JAR 与配置 |
| Fabric 安装完成服务端 | ✅ | 识别 launcher、libraries 和版本元数据 |
| Forge 1.20.1 安装完成服务端 | ✅ | 解析已知参数文件和标准启动模板 |
| NeoForge 1.21.1 安装完成服务端 | ✅ | 解析已知参数文件和标准启动模板 |
| 已有世界 | ✅ | 保留，不覆盖；首次启动后验证加载 |
| 已有模组/插件 | ✅ | 保留；不承诺全部兼容，只解释启动结果 |
| 仅世界存档 | 🟨 | 说明不是完整服务端，提供后续产品方向 |
| 客户端整合包 | 🟨 | 说明不能直接部署为服务端 |
| Forge/NeoForge 安装器 JAR | 🟨 | 识别为安装器，不在 P0 在线安装 |
| CurseForge/Modrinth manifest | 🟨 | 识别平台包，P0 不转换 |
| 任意自定义启动脚本 | 🟨 | 不执行；无法还原已知模板时停止 |
| RAR/7z/tar/tar.gz | ❌ | 上传阶段拒绝 |
| Bedrock 服务端 | 🟨 | 识别 Java 版边界，不创建实例 |
| 代理服务端 | 🟨 | 识别但不创建 P0 实例 |

## 6. Java 安装与选择

| 场景 | 状态 | P0 行为 |
|---|---:|---|
| Java 17 已安装 | ✅ | 记录绝对路径并用于 1.20.1 |
| Java 21 已安装 | ✅ | 记录绝对路径并用于 1.21.1 |
| 缺少 Java 17 | ✅ | 从 Ubuntu 官方 APT 安装 `openjdk-17-jre-headless` |
| 缺少 Java 21 | ✅ | 从 Ubuntu 官方 APT 安装 `openjdk-21-jre-headless` |
| APT 锁被占用 | ✅ 异常路径 | 等待有限时间后停止，说明占用情况 |
| 官方源不可用 | ✅ 异常路径 | 停止，不更换第三方源 |
| 用户已有其他 Java | ✅ | 不卸载、不替换全局默认值 |
| 第三方 PPA/Temurin 下载 | ❌ | P0 不使用 |
| `curl | sh` 安装 | ❌ | 永不作为 P0 路径 |

## 7. 上传与解压

| 限制 | 默认值 | 超限行为 |
|---|---:|---|
| ZIP 大小 | 4 GiB | 上传阶段拒绝或停止 |
| 解压预估总量 | 24 GiB | 不进入解压 |
| 单文件大小 | 8 GiB | 拒绝 |
| 条目数 | 100,000 | 拒绝 |
| 目录深度 | 32 | 拒绝 |
| 路径长度 | 1,024 字节 | 拒绝 |
| 压缩比 | 200:1 | 视为压缩炸弹风险 |
| 嵌套压缩包 | 不递归 | 作为普通文件保留 |
| 解压安全余量 | max(5 GiB, 文件系统容量 10%) | 低于余量停止扩大占用 |

### 7.1 必须拒绝的 ZIP 行为

- 路径穿越、绝对路径。
- 软链接、硬链接、设备文件、FIFO。
- 重复路径、大小写冲突。
- NUL 字符或无法规范化路径。
- 条目元数据与实际写入量异常。
- 解压目标逃出任务隔离目录。

## 10. 成功判定矩阵

| 证据 | 创建成功 | 启动成功 | 本机可玩 | 外网可玩 |
|---|---:|---:|---:|---:|
| MCSManager 实例存在 | 必须 | 必须 | 必须 | 必须 |
| 实例进程运行 | 不要求 | 必须 | 必须 | 必须 |
| 服务端就绪信号 | 不要求 | 必须 | 必须 | 必须 |
| 观察窗口无致命退出 | 不要求 | 必须 | 必须 | 必须 |
| 本机端口监听 | 不要求 | 建议 | 必须 | 必须 |
| 外部网络探测 | 不要求 | 不要求 | 不要求 | P0 不承诺 |

P0 最终结果文案最多承诺“服务已在本机准备完成”；没有外部探测证据时必须显示“外网连接未验证”。

## 11. 指标分母

P0 部署成功率只统计：

- Ubuntu 24.04 x86_64。
- MCSManager 版本已进入 `certifiedVersions`，首个版本为 v10.18.3。
- 使用本矩阵指定核心、MC、Java 和完整服务端 ZIP。
- 未超过上传/解压限制。
- 用户完成必要选择与 EULA。

矩阵外输入、用户取消、环境预检失败单独统计，不进入自动部署成功率分母。
