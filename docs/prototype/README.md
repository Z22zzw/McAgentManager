# MC AI Manager 功能原型

这是一个可点击、高保真的功能交互原型，用于评审功能区域、状态、文案和交互规则。

> 非视觉规范声明：本原型采用中性灰白、状态色和系统字体，仅帮助理解功能与信息层级；**不代表最终品牌、视觉语言、组件或动效设计**。正式设计需另行开展。

## 打开方式

无需安装依赖、无需启动服务，也不依赖 CDN。

1. 用浏览器直接打开当前目录中的 [`index.html`](index.html)。
2. 在桌面或移动宽度下操作即可。所有数据均为前端模拟状态，不会上传、读取、解压、创建、停止或删除真实服务器与文件。

## 推荐演示路径

### A. 核心开服闭环

1. 在“服务器”页查看运行中、已停止、异常三种实例状态。
2. 点击“上传服务端 ZIP”进入“AI 管家”。
3. 选择任意 ZIP 文件（或拖放文件）以触发模拟的安全预检和高置信度识别。
4. 修改实例名称（可选），明确选择离线登录选项，并独立勾选 Minecraft EULA 接受确认。
5. 点击“创建并启动实例”，观察全局任务步骤、进度和事实验证层级。
6. 完成后回到主页，对运行中或已停止实例演示启动、停止、重启。
7. 任务执行中可点击“中断任务”，演示“需要核对”而非自动重复执行的恢复规则。

### B. 失败与安全降级

1. 在 AI 管家点击“演示 Java 不兼容”，查看结论、确定性规则命中、日志片段证据和修复入口。
2. 在主页点击“查看清理方案”，先清理低风险缓存，查看重新测量后的磁盘空间。
3. 在“高级管理”中展开删除流程，输入完整的 `Forge 测试服` 才能启用删除按钮。
4. 删除只修改当前浏览器中的原型实例清单，明确展示无备份、不可恢复与预计释放空间。
5. 在“操作记录”中按实例和结果筛选，并展开任一条的技术详情。
6. 在“高级管理”演示安全新标签跳转说明与返回后的状态同步。

| 原型区域 | 对应需求 / 流程 | 原型覆盖内容 |
| --- | --- | --- |

| AI 管家 ZIP 工作区 | FR-AI-01～04、FR-DEPLOY-01～05、ZIP 导入部署主流程 | 上传入口、隔离与安全预检、识别置信度、实例名、显式离线登录、EULA 独立确认、创建/启动/验证 |
| 真实验证层级 | GATE-05、部署成功统一定义 | 进程启动、服务就绪、本机端口可用、外网未知的分层玩家文案 |

| 全局任务栏 | 任务状态模型、断线与恢复流程 | 检查/处理/确认/完成状态、逐步进度、中断后“需要核对” |
| 磁盘清理与删除 | FR 磁盘要求、磁盘不足与无备份删除流程 | 低风险优先、预计/实际释放、无备份风险、实例名精确确认、仅原型状态变更 |
| 操作记录 | FR-AUDIT-01～03、审计记录流程 | 玩家摘要优先、按结果和实例筛选、可展开技术详情、脱敏示例 |
| 高级管理 | FR 9.6、GATE-07、高级管理往返流程 | 新标签安全跳转说明、非 iframe、返回后重新同步与外部变更记录 |
| 可访问性 | NFR 12.5 | 响应式侧栏/主区、原生可键盘操作、可见焦点、ARIA 状态提示、`prefers-reduced-motion` |

## 原型状态覆盖

- 空：操作记录筛选无匹配项。
- 错误：Forge 测试服异常、Java 版本不兼容。
- 等待：等待 ZIP / 等待 EULA 与必要选择。
- 执行：全局任务栏与实例启动、停止状态。
- 成功：ZIP 创建并通过本机服务与端口验证、实例控制、缓存清理。
- 部分成功：历史磁盘清理记录，释放空间但未达到部署阈值。
- 中断待核对：任务栏的中断按钮。

## 已知边界

这是前端交互参考，不连接 MCSManager、DeepSeek Harness、文件系统、Java、网络或持久化审计服务。真实产品必须以任务服务、操作网关、MCSManager 和可验证的系统事实作为状态来源，不能以本原型中的按钮、动画或 AI 文案作为真实执行结果。
